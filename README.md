## 🧠 About This System

I don't split my work into "ML" vs "automation" vs "agents" — they're one pipeline. I train models,
I wire them into agents that make decisions, and I automate the plumbing (retries, conditional
routing, human-in-the-loop approval, webhook events) that turns a demo into something that runs
unattended.

Currently: **AI Automation Intern @ Tech Buzz**, building production n8n + LLM pipelines. Also:
final-year CS student whose research on multi-agent bias detection was selected from **305+
submissions** for the **IEEE IES GenAI Challenge 2026**, with a paper accepted at **IRAI 2026,
Melbourne**.
