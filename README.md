> `Python` · `FastAPI` · `PostgreSQL` · `Scikit-learn` · `Docker`

A full-stack recruitment automation system that matches candidates to job descriptions using NLP.

- Built RESTful APIs for resume upload, job creation, and ranked candidate retrieval
- Implemented **TF-IDF vectorization + cosine similarity** for automated candidate-job matching
- Integrated PDF parsing to extract structured data from uploaded resumes
- Containerized end-to-end with **Docker** for consistent, environment-agnostic deployment
